Future Integration Architecture Design Pattern

The application follows an isolated adapter pattern. The Java backend interacts with an interface: PredictionService, currently backed by DemoPredictionService.

Upon model deployment, a remote MlInferenceService implementing PredictionService will make asynchronous REST calls to the Python/FastAPI microservice hosting the trained model:

[Spring Boot MVC] → [PredictionService] → [FastAPI POST /v1/predict] → [XGBoost Model Pipeline] → JSON Response
